## Global constraints (repeated from the brief and spec; they apply to every task)

**Cost and scope**
- **$0 total, with no credit card, paid plan or API key anywhere.** If a step would need one, STOP and ask the founder.
- No Anthropic API, Google Places, email sending, GoHighLevel, deployment, background jobs or polite fetcher.
- Local only: `pnpm dev` binds to `127.0.0.1`. The code stays deployable (Postgres dialect, `requireUser()`, `workspaceId`).
- Never widen scope. Ideas go in `docs/ideas.md`. Ask before any architectural change.

**TDD and git**
- RED → GREEN → REFACTOR. The test is written first and **seen failing** for the right reason. Code written before its test is deleted.
- Config-only tasks (no behavior) are verified by a command instead of a unit test, and say so.
- Commit after each passing task with a Conventional Commit (`feat(db): …`, `chore(tooling): …`, `test(design): …`).
- Never commit `.env*` files, keys, real personal data or real firm data. All seed firms are fictional and use the reserved `.example` domain (RFC 2606) and 555-01xx phone numbers.
- For anything unexpected, use systematic debugging: reproduce → root cause → hypothesis → fix → regression test. Never guess.

**Definition of done (whole phase)**
- `pnpm typecheck && pnpm lint && pnpm test && pnpm e2e` all pass, with the output pasted.
- axe reports 0 violations, and the contrast tests pass.
- Every touched screen has its 6 states (loading, empty, error, success, disabled, partial), checked in light and dark, at 320, 768 and 1440px, at 200% zoom, and keyboard-only.
- AuditLog is written on every create, update and delete.
- README and CHANGELOG are updated. Code review is requested, and every Critical or Important finding is fixed or deferred.

**Design rules (brief Part 8)**
- Semantic tokens only, exactly 3 shadows, Inter 400/500/600 with `tabular-nums` on numbers, and sentence case.
- `gap-*`, never `space-y-*`. No manual `dark:` overrides and no hand-set z-index on overlays.
- The banned "AI slop" list applies.
- Motion follows its frequency rules, never uses `transition: all`, and honors reduced motion.
- shadcn on **Base UI** only; never import Radix.

**Guardrails:** brief Part 11 applies in full and is copied into `CLAUDE.md` (Task 40).
