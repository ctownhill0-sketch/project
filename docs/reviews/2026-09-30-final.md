## Design review

Screenshots of every page (23 pages × 1440/768/320 × light/dark = 138 files) are in `docs/screenshots/pages/`. Findings, ranked. **None are 🔴.**

1. 🟠 **Call-block mode and ROI Present mode had no h1.** _Why:_ screen-reader users navigate by headings. _Fix (done):_ both now have one, and a new e2e test checks that every page and mode has exactly one h1.
2. 🟠 **"Save day" was a primary button on every pilot card.** _Why:_ one primary action per view. _Fix (done):_ it's now outline.
3. 🟠 **Script "Edit" buttons stretched full width on the fair-housing page.** _Fix (done):_ they now size to their label.
4. 🟡 **Present mode still shows the app sidebar.** _Why:_ on a screen-share, the prospect sees the navigation (no firm names). _Fix:_ none yet. Use the browser's full screen (⌃⌘F) or share only the window area. An overlay would hide focus behind it (WCAG 2.4.11), so it's left for later.
5. 🟡 **On phones, the ROI results sit below the form.** They scroll into view. Present mode is the phone-friendly view.
6. 🟡 **The pilot card's three figures are tight at 320px** ("Projected at day 14" wraps). Still readable, with no overflow.
7. 🟡 **Placeholders "0" and "unknown" in the pilot grid look like values.** They're muted placeholder text, and saving blank fields stores 0 or unknown exactly as shown.
